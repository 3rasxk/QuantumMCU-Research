\section{Related Work}
Dense statevector simulators and their exponential memory demand are well documented~\cite{TODO-statevector-memory}, as are GPU and CPU simulators such as Qiskit Aer~\cite{TODO-qiskit-aer}. Quantum-circuit simulation on embedded hardware has been explored~\cite{TODO-embedded-quantum-sim}, and timing measurement on microcontrollers with an external reference is common practice~\cite{TODO-mcu-timing}. The circuits we use are textbook constructions (QFT~\cite{TODO-qft}, Grover search~\cite{TODO-grover}). We do not claim novelty over this literature; the repository contains no reference list, so these citations are placeholders to be completed by the authors.
